# Book UI React App

A React + TypeScript frontend application connected to an ASP.NET Core Web API for managing books.

---

# Features

- Fetch books from ASP.NET Core API
- Display books as responsive cards
- Show / Hide book details
- React functional components
- TypeScript interfaces
- Fetch API integration
- CSS Grid responsive layout

---

# Technologies Used

- React
- TypeScript
- Vite
- CSS3
- ASP.NET Core Web API

---

# Installation

Clone repository:

```bash
git clone https://github.com/dhanushJZtec/Book_UI.git
```

Go to project folder:

```bash
cd Book_UI
```

Install dependencies:

```bash
npm install
```

Run project:

```bash
npm run dev
```

---

# Backend Requirement

Make sure ASP.NET Core Books API is running before starting frontend.

Example:

```text
http://localhost:5062
```
